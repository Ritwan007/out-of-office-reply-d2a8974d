`main.ts` writes one out-of-office auto-reply line (109 characters) to `/output/entry.txt`:

> I'm on vacation until Thursday. My auto-reply wrote this auto-reply. We are both on vacation. Nobody is home.

Run it with Node 22: `node main.ts` (or set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` lands).
